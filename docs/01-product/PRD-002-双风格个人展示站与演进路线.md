# 双风格个人展示站与演进路线（V0.4）

## 1. 背景与定位

在完成 `PRD-001`（多用户在线简历平台骨架与 P1–P3 核心能力）之后，为了优先解决个人求职展示、作品集沉淀与双赛道叙事需求，项目进入以**第一期双风格个人展示站**为核心交付物的 V0.4 阶段。

V0.4 围绕同一套身份（李佳铭 / `SUBMING`），提供可即时切换的双岗位视角：
- **AIGC 漫剧制片视角（`aigc`）**：聚焦 AI 漫剧工作流、工业化管线与代表作品。
- **全栈开发工程师视角（`dev`）**：聚焦生产级 Web 系统、前后端架构与工程交付。

## 2. 第一期核心交付（已落地 `v0.4.0`）

1. **双风格首页（`/`）**：
   - `aigc` 模式：暖白宣纸大刊风格（`#F6F4EF` + `#C84B31`），巨型刊头 `SUBMING`、4 帧对称换刊封面、3 篇左右交替镇馆跨页、粘性人物专访与视觉年表。
   - `dev` 模式：深空午夜蓝黑风格（`#070B14` + `#3B82F6`），命令行状态标头、3 大工程系统切换工作台（实机画面 / 4 层架构拓扑双视图）与纯工程镇馆跨页。
2. **二级菜单作品集（`/portfolio`）**：
   - 支持 `全部作品` / `漫剧作品` / `全栈工程` 分类筛选。
   - 详情弹窗支持 `Esc` 关闭，已预留原生 `<video>` 播放器字段（`videoUrl` / `posterUrl`），供后续接入阿里云 OSS + CDN。
3. **双岗位正式可打印简历（`/resume`）**：
   - 支持双岗位简历切换，内嵌 `@media print` 纯白 A4 打印一致性内核。

## 3. 三期演进路线

| 阶段 | 状态 | 目标与范围 |
|---|---|---|
| **第一期** | ✅ 已发布（`v0.4.0`） | 双风格个人主页、作品集与可打印正式简历；预留 OSS + CDN 视频播放位 |
| **第二期** | ⏸ 已留基座 | 恢复并打磨在线简历编辑工作台（`/app/*`、`/login`、`/admin`）与 Hono + SQLite 存储 |
| **第三期** | ⏸ 远景规划 | 将个人品牌展示站与公开多用户简历平台（`/r/:slug`）融合 |

## 4. 隐私与内容约束

- 所有商业合作或私有项目对外展示必须严格脱敏，不得泄露客户域名、AppID、测试口令与私密仓库链接。
- 公开页面不暴露个人手机号，仅保留邮箱与公开 GitHub 主页。
